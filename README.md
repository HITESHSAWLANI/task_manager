# 3D Task Tracker

A modern, visually stunning task management application featuring glassmorphism design, 3D effects, and smooth animations.

## Features

- **Glassmorphism UI** - Frosted glass effect with backdrop blur and soft borders
- **3D Hover Effects** - Interactive cards with perspective, translateZ, and rotation transforms
- **Animated Background** - Floating gradient orbs with smooth continuous animation
- **Local Storage Persistence** - Tasks are saved and restored automatically
- **Real-time Statistics** - Live counter showing total, pending, and completed tasks
- **Micro-interactions** - Button ripples, input validation shake, completion animations

## Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Animations, Transforms)
- Vanilla JavaScript (ES6+)
- Local Storage API

## Usage

1. Open `index.html` in any modern web browser
2. Type a task in the input field
3. Click "Add Task" or press Enter to add
4. Click "Complete" to mark a task as done
5. Click "Delete" to remove a task
